# gh-clip storage

This private repo is managed by [gh-clip](https://github.com/SamuelBisberg/gh-clip), a GitHub CLI extension that acts as a secure cross-device clipboard.

- `clips/` holds your saved clips.
- `retention.json` sets how long clips are kept.
- `.github/workflows/cleanup.yml` runs once a day and deletes expired clips and Gists.

Manage everything with `gh clip`. See the [gh-clip repository](https://github.com/SamuelBisberg/gh-clip) for details.
