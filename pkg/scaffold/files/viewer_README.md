# gh-clip viewer

This public page is the mobile viewer for [gh-clip](https://github.com/SamuelBisberg/gh-clip), a GitHub CLI extension that acts as a secure cross-device clipboard. It is served by GitHub Pages and shows a shared clip so you can tap to copy it on your phone.

It is created and updated by `gh clip init`. See the [gh-clip repository](https://github.com/SamuelBisberg/gh-clip) for details.
